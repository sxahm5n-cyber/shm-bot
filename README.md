# 🤖 Shm Bot - TikTok Automation Bot

بوت تلقائي لنشر الفيديوهات على TikTok بأفضل أوقات عالعالم!

## ✨ الميزات

✅ **جدولة الفيديوهات** - نشر فيديو واحد يومياً  
✅ **أفضل أوقات النشر** - حساب أحسن وقت عالعالم تلقائياً  
✅ **استقبال من Telegram** - أرسل الفيديوهات عبر Telegram  
✅ **بايو طويل** - 1500 نقطة تحت بعضها  
✅ **هاشتاجات ذكية** - إضافة هاشتاجات تصعد الفيديو  
✅ **قلوب تلقائية** - وضع قلب على التعليقات  

---

## 🚀 البدء السريع

### 1️⃣ المتطلبات

- Python 3.8+
- pip (مدير الحزم)
- حساب TikTok
- Telegram Bot Token

### 2️⃣ التثبيت

```bash
# استنساخ المستودع
git clone https://github.com/sxahm5n-cyber/shm-bot.git
cd shm-bot

# تثبيت المكتبات
pip install -r requirements.txt
```

### 3️⃣ التكوين

عدّل ملف `config.py`:

```python
TELEGRAM_BOT_TOKEN = "YOUR_TOKEN_HERE"
TELEGRAM_CHAT_ID = YOUR_CHAT_ID
TIKTOK_USERNAME = "shm.ro1"
TIKTOK_PASSWORD = "YOUR_PASSWORD"
```

### 4️⃣ التشغيل

```bash
# تشغيل البوت الرئيسي
python main.py

# في نافذة أخرى - تشغيل معالج Telegram
python telegram_handler.py
```

## 📖 كيفية الاستخدام

### إرسال الفيديوهات

1. افتح Telegram وأرسل الفيديوهات للبوت
2. البوت سيحفظها تلقائياً
3. سيتم النشر في أفضل وقت عالعالم

### الأوامر

- `/start` - بدء البوت
- `/status` - حالة البوت
- `/queue` - عرض قائمة الفيديوهات

---

## 🎯 كيف يعمل البوت

1. **استقبال الفيديوهات** من Telegram
2. **تخزينها** في مجلد `videos`
3. **حساب أفضل وقت** عالعالم للنشر (8 AM, 12 PM, 6 PM, 8 PM UTC)
4. **جدولة النشر** تلقائياً
5. **إضافة البايو** (1500 نقطة)
6. **إضافة الهاشتاجات** المناسبة
7. **وضع قلب** على التعليقات

---

## ⚙️ التكوينات المتقدمة

### تغيير أوقات النشر

في `config.py`:

```python
BEST_POSTING_TIMES = [
    "08:00",  # صباح
    "12:00",  # ظهر
    "18:00",  # مساء
    "20:00",  # ليل
]
```

### تغيير الهاشتاجات

```python
DEFAULT_HASHTAGS = "#FYP #ForYou #Trending #TikTok #Viral"
```

### تغيير البايو

```python
BIO_DOTS = "•" * 1500  # عدد النقاط
```
